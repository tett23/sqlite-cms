記事置き場を作った。
白背景に黒文字、リンクは青。それだけの見た目にしてある。

表示の確認用に、いくつかの記法を並べておく。

> 引用はこのように表示される。

コードブロックはこう。

```haskell
main :: IO ()
main = putStrLn "hello"
```

インラインの `code` と、**強調**と、[リンク](https://example.com)。

1. 番号付きリスト
2. 二つ目

GFM の記法も通る。

| 記法 | 対応 |
|---|---|
| 表 | する |
| ~~取り消し線~~ | する |

- [x] タスクリスト
- [ ] 未完了の項目

URL は www.example.com のように書くだけでリンクになる。
サイト内のリンクは[自己紹介](/about)のように書ける。
脚注も使える[^1]。

画像は記事リポジトリの `content/media/` に置き、`/media/` から参照する。
