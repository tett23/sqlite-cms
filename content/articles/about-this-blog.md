このブログは、記事の Markdown を Git で管理し、ビルド時に全記事を一つの SQLite ファイルへ変換して配信している。
ブラウザは起動時にその SQLite を取得し、以後の記事一覧と記事表示はローカルの DB 参照だけで動く。
記事から記事への遷移に、ネットワークアクセスは発生しない。

記事ごとに JSON を配る方式ではなく単一ファイルを選んだのは、デプロイの原子性のためだ。
DB はコンテンツハッシュ付きのファイル名で配信されるので、参照が切り替わった瞬間には必ず完全なスナップショットが見えている。
一覧にはあるのに本体がない、という中途半端な状態は原理的に起きない。

画像は DB に入れず、静的ファイルとして配信する。
テキストだけなら DB は記事が千本あっても数 MB に収まる。

## 使っているもの

- React + Vite + Tailwind
- sql.js（ブラウザ内で SQLite を開く）
- Cloudflare（静的アセット配信）
