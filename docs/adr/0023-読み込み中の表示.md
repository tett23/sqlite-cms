# 0023 読み込み中の表示

## 状態

採用。

## 決定

JS と DB を読み込むまでの間、読み込み中の表示（回転する円と「読み込み中」の文字）を出す。

### 表示

- `web/index.html` の `#root` の中に、読み込み中の表示を直接書く。スタイルも `<style>` で同じファイルに書く。JS と CSS のファイルを待たずに描画させるためである。
- React は、DB を読み込むまで同じクラス（`loading`）で同じ表示を出す。JS が動き始めても見た目が変わらない。
- 要素には `role="status"` を付け、読み上げにも読み込み中であることを伝える。
- `prefers-reduced-motion: reduce` のときは円を回さない。
- 色はアクセシビリティの基準（文字は 4.5:1 以上）を満たす灰色（`#555555`）にする。

### React の起動を最初の描画の後にする

`main.tsx` は、`requestAnimationFrame` の後の `setTimeout` で React を起動する（Shiki の読み込み開始も同じ時点）。

起動をすぐに行うと、ブラウザが `index.html` の表示を描く前に React が画面を置き換えることがある。
その場合、最初の描画が JS の実行の後になる。
Lighthouse は、実際の最初の描画までに始まった通信（本体の JS に加え、Shiki の JS）をすべて最初の描画に必要なものとみなして、遅い回線での時間を見積もる。
計測では、トップページの最初の描画が JS の実行の後（112 ms）になり、見積もりが 6.5 秒になっていた。
起動を 1 フレーム遅らせると、どのページでも `index.html` の表示が最初に描かれる（26〜51 ms）。

### 計測結果

手元の Apple Silicon で、`sqlite-cms serve` の配信を計測した。

| 指標 | 変更前 | 変更後 |
|---|---:|---:|
| First Contentful Paint | 6.5 秒 | 3.9 秒 |
| Speed Index | 6.5 秒 | 3.9 秒 |
| Largest Contentful Paint | 13.4 秒 | 13.4 秒 |

パフォーマンスの点数は、トップページが 59 点から 66 点になった。ほかのページは 55〜66 点で、ほぼ変わらない。
読み込み中の表示が改善するのは最初の描画だけで、本文が表示されるまでの時間（Largest Contentful Paint）は変わらないためである。

### 本文の表示が遅い理由

Largest Contentful Paint が遅いのは、`sqlite-cms serve` が応答を圧縮しないためである。
Lighthouse は遅いモバイル回線を模して時間を見積もるので、転送量がそのまま時間になる。

| ファイル | 圧縮なし | gzip |
|---|---:|---:|
| 本体の JS | 601 KB | 185 KB |
| Shiki の JS | 1,069 KB | 161 KB |
| sql.js の wasm | 659 KB | 323 KB |
| DB | 53 KB | 7 KB |

`serve` の前に gzip で圧縮する中継を置いて計測すると、Largest Contentful Paint は 4.8 秒、点数はトップページと自己紹介が 81 点、記法の一覧が 70 点になった。
本番の Cloudflare は応答を圧縮するので、実際の値はこちらに近いと見込む（本番での計測はしていない）。

Shiki の読み込みを DB の読み込みの後に遅らせる方法も試したが、Largest Contentful Paint は変わらなかった。
本文の表示の前に Shiki の通信が始まることに変わりはなく、見積もりに含まれるためである。

## 実装しないこと

- `serve` での応答の圧縮。計測の値を本番に近づけられるが、圧縮の実装か依存が要るので、別に決める。
- 本文の形を模した表示（スケルトン）。
- Shiki の読み込みを遅らせること。上のとおり効果がなかった。

## テスト設計

- DB と wasm の応答を 2 秒遅らせる中継を置き、ブラウザで読み込み中の表示が出てから本文に置き換わることを確認した。
- Lighthouse の実測値（`observedFirstContentfulPaint`）で、全ページの最初の描画が JS の実行より前になることを確認した。

## トレードオフ

- React の起動が 1 フレーム（約 16 ms）遅れる。
- 読み込み中の表示のスタイルが、Tailwind の外（`index.html`）にある。
- 点数は Largest Contentful Paint で大きく引かれたままである。
