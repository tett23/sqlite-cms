# 0008 ビルダーの改名

## 状態

採用。
0006 と 0007 の「ビルダーは `build-db/` に置くバイナリ `build-db`」という名前と配置を置き換える。
ビルダーの動作は変えない。

## 決定

- バイナリ名（Cargo のパッケージ名）を `sqlite-cms` にする。
- crate のディレクトリを `build-db/` から `cli/` に移す。
- エラーメッセージの接頭辞も `sqlite-cms:` にする。

npm スクリプトの `build:db` と `test:db` は、コマンド名ではなく処理内容（DB の生成とそのテスト）を表す名前なので変えない。
内部の関数名 `build_db_bytes` も同じ理由で残す。

## 採用の理由

ビルダーはこのリポジトリのコマンドラインの入口であり、リポジトリと同じ名前で呼べるほうが用途を思い出しやすい。
ディレクトリ名は、中身が特定の処理（DB の生成）ではなくコマンドラインツールであることを示すものにした。
今後、全文検索の索引作成などの処理を同じバイナリのサブコマンドとして足す場合も、名前を変えずに済む。

## 実装しないこと

- サブコマンドの導入。現在の処理は一つであり、引数はリポジトリルートだけで足りる。

## テスト設計

- `cargo test` と vitest が改名後のパスで通ること。
- `npm run build` が `cli/` のバイナリで DB を生成できること。

## トレードオフ

- ADR 0006 と 0007 の本文には旧名 `build-db` が残る。ADR はコミット後に変更しないため、この ADR が対応を示す。
