# 0057 外へのリンクを新しいタブで開く

## 状態

提案。

## 決定

サイトの外へのリンクを、新しいタブで開く（`target="_blank"`、`rel="noopener"`）。

- 外とみなすのは、http か https で、表示しているページと違うオリジンのリンクだけ（`web/src/externalLink.ts` の `isExternal`）。サイト内のパス、ページ内の `#…`（脚注など）、`mailto:` などは今までどおり。サイト内のリンクは、今までどおり SPA の中で移る（ページを読み直さない）。
- 対象は、本文（Markdown のリンク、自動リンク、本文に書いた HTML の `<a>`）とヘッダ（`content/header.md`）、リンクカード、フッタのライセンスのリンク。
- 本文の HTML は、`target` と `rel` を取り除いてから（0018）、描くときに付ける。書き手が `target` を書いても効かない。
- `rel="noopener"` で、開いた先のページから元のページを操作させない。`noreferrer` は付けない（リンク先に、どこから来たかを伝える）。
- サーバーでの描画（テスト）では、オリジンが分からないので、http と https のリンクをすべて外とみなす。

## 実装しないこと

- 新しいタブで開くことを、アイコンや読み上げの文で知らせること。
- 同じオリジンを絶対 URL で書いたリンクを、SPA の中で移ること（今までどおり、ページを読み直して移る）。

## テスト設計

- `isExternal`：ほかのオリジンの http と https（ポートの違い、大文字を含む）を外とみなし、同じオリジン、サイト内のパス、相対のパス、`#…`、`mailto:`、`javascript:`、`//…` を外とみなさないこと。オリジンが分からないときは http と https をすべて外とみなすこと。
- MarkdownBody：Markdown のリンクと HTML の `<a>` の外へのリンクに付け、サイト内、相対、`mailto:`、脚注のリンクに付けないこと。自動リンク、画像のリンク、リンクカードの既存のテストを改めた。
- E2E：トップの外へのリンクに付き、ヘッダと本文のサイト内のリンクに付かないこと。フッタのライセンスに付き、RSS に付かないこと。

## トレードオフ

- 外へのリンクは、同じタブで開きたい人も新しいタブで開く（中ボタンや修飾キーでの操作は、ブラウザに任せたまま）。
